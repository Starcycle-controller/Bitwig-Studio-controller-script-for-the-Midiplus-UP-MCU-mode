Bitwig Studio Controller API - complete action reference
==========================================================

Captured via a temporary startup diagnostic in MidiplusUP-MCU.control.js
(application.getActionCategories(), each category's getActions()). Use
this to look up the correct id for safeInvokeAction(id, popupText)/
application.getAction(id).invoke() before guessing one - guessing wrong
costs a guess-test-fix round trip on real hardware (as Consolidate did).

781 actions across 20 categories. Complete (unlike the
first capture attempt, which got truncated by the console's scrollback
buffer) - confirmed by the dump's own "Total" line matching the count here,
and the capture starting right after the script's own "Initializing..."
line and ending at "Script Ready".

Format: one action per line, "id" -> "Display Name" (as shown in Bitwig's
own Commander/menus). Categories are Bitwig's own grouping, sorted
alphabetically here; actions within each category are sorted by display
name for easy scanning.
