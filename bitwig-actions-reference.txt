====================================================================================

Captured via a temporary startup diagnostic in MidiplusUP-MCU.control.js
(application.getActionCategories(), each category's getActions(), printing
"id" / "name" per action - see git history for the diagnostic code, since
removed once this was saved). Format per line: "id" / "Display Name".

PARTIAL DUMP - the console's scrollback buffer truncated the START of the
output, so an unknown number of categories/actions before "Consolidate"
below are missing (likely includes core Transport/Track/Device/Edit-type
categories - re-run the diagnostic and capture output in smaller chunks,
or immediately after reload before other console spam pushes it out, to
fill this in later if needed).

781 actions across 20 categories total (per the dump's own summary line) -
this file only contains the categories that fit in the buffer (from partway
through one category, through "Clip Launcher").
