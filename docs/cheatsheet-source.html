Midiplus UP - Quick Reference

Full details: README.md / MidiplusUP-User-Guide.pdf - Starcycle + Claude

Modes

TRACK/IO Mixer - Vol/Pan
SEND Sends - send levels (SHIFT = 9-16)
PLUG-INS / F1-F8 Device - macros (encoders); Vol or macros (faders, FLIP)
PAN Gain-Stage - TRLVL device Gain/Pan (needs TRLVL on track!)
RETURNS Same modes, on Return tracks
B.T.A. Scene - clip launcher + mixer, wheel selects/launches
FLIP Swap faders/encoders Vol<->Pan/Macro

Wheel (needs SCROLL mode)

(plain) Scrub, whole bars
SHIFT Shift loop by a bar
OPTION Halve/double loop length
CTRL Step to next/prev clip (click one first!) - or step devices in Device mode
SHIFT+CTRL Duplicate clip (right); configurable
ALT+CTRL Duplicate/delete track; configurable, can disable
ALT Adjust last-clicked GUI parameter
SHIFT+ALT Nudge selected item (click it first!)

Scene Mode Wheel (B.T.A.)

(plain) Select scene row (doesn't move on SHIFT/CTRL below)
SHIFT+wheel Select track - configurable: single track or page bank
CTRL+wheel Same options, independent 2nd modifier - off by default

Mixer Layout (F1-F8, Mixer/Scene mode)

F1 / F2 Recall layout preset - 3 configurable Show/Hide slots each
F3-F8 Toggle one mixer section each - configurable, off by default

Other Combos

SHIFT+PLUG-INS EQ Mode - jump to last EQ in chain
DRAW Cycle automation write mode
SHIFT+DRAW Toggle automation write arm
OPTION+DRAW Show/hide automation lanes
SHIFT+F1-F8 Store mixer snapshot
OPTION+F1-F8 Recall mixer snapshot
SMPTE/BEATS Toggle F1-F8 green state
SELECT x2 Fold/unfold group track
ALT+B.T.A. Toggle metering plugin window
SESS/ARR Toggle Mix / Arrange panel layout
SHIFT+SESS/ARR Toggle clip launcher sidebar (in Arrange)

Master Wheel (MASTER mode)

turn Master volume (this unit has no physical master fader)
turn (plugin mode) Open/close metering plugin - never touches volume - opt-in

Encoders / Faders

Push (Mixer) Center pan
Push (Device) Fine-turn / reset / open window - see Prefs
SHIFT+turn Stepped or fine adjust - see Prefs
SHIFT+HOME Add named cue marker ("Bar N")
ALT+F8, then F8 Fader position self-test
Setup reminders: Gain-Stage mode needs a device named exactly TRLVL on the track (Bitwig's "Tool" device works). Wheel combos need the hardware's wheel-mode selector on SCROLL. CTRL/SHIFT+ALT clip actions need a clip already clicked/selected with the mouse first - there's no button gesture that can select one from nothing.
