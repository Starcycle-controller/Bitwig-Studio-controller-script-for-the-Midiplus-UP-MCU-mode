## Traditional Chinese (繁體中文) — to send

**主旨：產品功能建議 — UP/UP+ 控制器 LCD 顯示與 Unicode 字元支援**

您好，

我們是使用 MIDIPLUS UP 控制器（MCU 模式）搭配 Bitwig Studio 開發自訂控制腳本的使用者。首先想說，這台控制器的做工與功能規劃真的很棒，無論是馬達推桿還是多功能搖輪，操作起來都非常順手，很感謝貴公司用心打造這樣優秀的產品！

在開發過程中，我們有兩個功能建議，希望能提供給貴公司參考，或許能讓 UP/UP+ 系列在未來的韌體更新中變得更加好用：

**1. LCD 色塊顯示（對應音軌顏色）**

目前每個聲道的 LCD 顯示為純文字，如果韌體能夠開放對應的 MIDI／SysEx 指令，讓我們可以設定每個聲道 LCD 的色塊或背景顏色，和 DAW（例如 Bitwig Studio）裡設定的音軌顏色同步顯示，對使用者在辨識聲道時會有很大的幫助，操作起來也會更直覺。如果目前的 LCD 硬體本身就支援顯示顏色，只是還沒有開放對應的控制指令，那就更棒了！

**2. Unicode 字元支援**

目前 LCD 顯示的字元集看起來偏向基本 ASCII 範圍，如果韌體未來能夠支援更完整的 Unicode 字元（例如各國語言字元、特殊符號等），會讓聲道名稱、參數名稱等顯示更清楚，對於使用非英文命名習慣的使用者（包含我們自己）會是很實用的加分功能。

以上都只是我們在使用過程中想到、覺得或許值得參考的建議，如果貴公司已經有類似的規劃，或是有其他建議，也非常歡迎回覆與我們分享。再次感謝貴公司提供這麼優秀的產品，祝工作順利！

## English gloss (for your own reference, not to send)

**Subject: Product feature suggestion — UP/UP+ controller LCD display & Unicode support**

Hello,

We're using the MIDIPLUS UP controller (MCU mode) together with a custom
Bitwig Studio control script we've been developing. First, we wanted to say
the build quality and feature design of this controller are genuinely great —
the motorized faders and the multi-purpose jog wheel both feel excellent to
use. Thank you for putting so much care into such a great product!

While developing our script, we came up with two feature suggestions that
might be worth considering for a future firmware update to the UP/UP+ series:

**1. LCD color blocks (matching track colors)**

Each channel's LCD currently shows plain text only. If the firmware could
expose a MIDI/SysEx command to set a color block or background color per
channel's LCD — matching the track color set in the DAW (e.g. Bitwig
Studio) — it would make it much easier for users to visually identify
channels, and would feel more intuitive overall. If the LCD hardware
already supports color display and it's simply not yet exposed via a
control command, that would be even better.

**2. Unicode character support**

The LCD's character set currently appears to be limited to basic ASCII. If
the firmware could support a fuller Unicode character range in the future
(e.g. characters from various languages, special symbols), it would make
track names and parameter names much clearer to read — a genuinely useful
improvement for users (including us) who don't always use English-only
naming.

These are just suggestions that came up during our own use, in case they're
useful. If you already have similar plans in the works, or other feedback,
we'd love to hear back. Thanks again for such a great product, and best
wishes with your work!

Warm regards,
[Your name / signature]
